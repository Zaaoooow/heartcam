# 那些年 · 快拍三连 ♥

一个纯前端（无构建、无依赖）的怀旧风三连拍照相亭 ——
灵感来自青春剧《当我飞奔向你》的氛围和 2000 年代末台式 / 直板数码相机（digicam）的随手拍质感，每次按下快门连拍 3 张，打在一张相纸卡上。

## 怎么跑起来

由于浏览器摄像头权限要求安全上下文，推荐本地起个小服务器：

```bash
cd heartcam
python3 serve.py              # 自带 no-cache 头
# 或: python3 -m http.server 8642
# 打开 http://localhost:8642
```

（直接双击 index.html 也可以玩，某些浏览器可能不给摄像头权限。）

## 功能

- **三连拍照相亭**：按一次快门 = 带倒计时连拍 3 张，取景器里显示「快拍 1/3」
- **只保留一种滤镜**：2006 年手持 digicam 质感（CCD 噪点、暖调、闪光感、轻微星芒）
- **相纸卡打印**："胶片实验室"流水线一步步做出来：自动白平衡 → 色调曲线 → CCD 彩噪 → 颗粒 → 色度渗色 → halation → 星芒 → 暗角
- **3 张照片纵向排进一张米白相纸**，最底部盖上机械感日期章
- **相册**（IndexedDB）、灯箱大图、一键下载原图、按拍摄日期分导航
- **音效**：快门声 / 倒计时哔哔声都是 WebAudio 现场合成的，无音频文件

## 结构

```
index.html        页面骨架
styles.css        粉色相纸风样式
scripts/app.js    UI / 相机 / 三连拍会话 / 相纸卡合成 / 相册逻辑
scripts/filters.js 滤镜 + 像素处理流水线
scripts/storage.js IndexedDB 封装
scripts/audio.js  合成音效
serve.py          无缓存的静态服务器
```
