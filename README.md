# 那些年 · 拍立得小站 ♥

一个纯前端（无构建、无依赖）的怀旧风拍照小站 ——
灵感来自青春剧《当我飞奔向你》的氛围和 2000 年代末台式 / 直板数码相机（digicam）的随手拍质感。

## 怎么跑起来

由于浏览器摄像头权限要求安全上下文，推荐本地起个小服务器：

```bash
cd heartcam
python3 -m http.server 8642
# 打开 http://localhost:8642
```

（直接双击 index.html 也可以玩，某些浏览器可能不给摄像头权限。）

## 功能

- **取景器**：镜像预览、九宫格、闪光灯 / 延时 / 翻转镜头 / 画幅切换
- **5 个滤镜配方** (`scripts/filters.js` 里的 `FILTERS`)：
  - 青春剧 — 透亮粉橘 + 轻光晕
  - 证件 selfie — 2006 年闪光灯随手拍
  - 旧监控 — CCTV 扫描线
  - 巨头闪光灯 — 巨型闪光灯教室黄昏
  - 清爽橘 — 汽水味的下午
- **"胶片实验室"流水线**：自动白平衡 → 色调曲线 → 饱和度 / 橙青调 → CCD 彩色噪点 → 颗粒 → 色度渗色 (JPEG 糊) → halation 溢光 → 星芒 → 暗角 → 扫描线 → 日期戳
- **决定性瞬间**：测光找到最亮点自动打星芒
- **拍立得相册**：IndexedDB 存到本地、按滤镜分收藏、灯箱大图、一键下载原图
- **音效**：快门声倒计时哔哔声都是 WebAudio 现场合成的，无音频文件

## 结构

```
index.html        页面骨架
styles.css        粉色相纸风样式
scripts/app.js    UI / 相机 / 相册逻辑
scripts/filters.js 滤镜 + 像素处理流水线
scripts/storage.js IndexedDB 封装
scripts/audio.js  合成音效
```

想加自己的滤镜？往 `FILTERS` 里加一个配方就行（`params` 里都是 0–100 的小数）。
